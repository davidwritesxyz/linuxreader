# 

```
--authfile=path
       Path of the authentication file. Default  is  ${XDG_RUNTIME_DIR}/containers/auth.json
       on  Linux, and $HOME/.config/containers/auth.json on Windows/macOS.  The file is cre‐
       ated  by  podman  login.  If  the   authorization   state   is   not   found   there,
       $HOME/.docker/config.json is checked, which is set using docker login.
```
